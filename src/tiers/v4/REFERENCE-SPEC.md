# BMM Bangalore Reference Site — Design Spec

## Colors
- Body bg: white `rgb(255,255,255)`
- Body text: dark gray `rgb(51,51,51)`
- Accent/CTA: orange `rgb(245,98,33)` / `#f56221`
- Section headings (mission): white `rgb(255,255,255)` on dark bg
- Section body (mission): light purple `rgb(218,177,217)` / `#dab1d9`
- Hero section bg: near-black `rgb(2,1,6)` with background image
- Footer bg: transparent (inherits white)

## Typography
- Display font: **Grechen Fuemen** (cursive/handwritten feel) — 62px/600
- Heading font: **Poppins** — 20-35px/500-600
- Body font: **Archivo** — 16px/400
- System fallback: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, etc.

## Page Structure (Homepage)
1. **Nav** — Logo (Rotary) + dropdown menus: THE RACE, PARTNERSHIP, PHILANTHROPY, ABOUT, Race Route Map, FAQs
2. **Hero** — Dark bg with background image, logo images, certification badges (AIMS, Certified Course, Armed Forces)
3. **CTA Banner** — "Final Timings & Certificate download" link
4. **Partners 2025** — H2 heading + image carousel with sponsor logos and tier labels
5. **"WHAT A NIGHT"** — Grechen Fuemen display font, orange color, video play button, editorial copy
6. **"Gear Up Now..."** — Orange H2, CTA text
7. **Mission Sections** — Dark bg, each with Grechen Fuemen title + Archivo body:
   - "Run To Make A Difference"
   - "Run For Hope"
   - "Run For Those Who Can't"
   - "Run For A Smile"
   - "Run For The Earth"
8. **"The BMM Story"** — Grechen Fuemen title + narrative paragraph
9. **Footer** — 3-column: BMM description + contact, Site Links, Instagram feed grid
